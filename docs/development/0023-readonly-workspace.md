# 受限工作区与只读文件预览

日期：2026-11-28。基于 b42bece，开发前重新阅读 ADR-0001。用户确认优先完整 Agent 产品开发，安装打包后置；仓库外的打包探针没有纳入项目。

## 当前问题与最小闭环

此前只有聊天和模型设置，没有文件访问范围。此次建立显式、进程内的目录授权与只读浏览，不创建持久 Workspace 业务实体、不新增数据库，也不修改 Durable 的执行与恢复机制。

- Rust 增加系统目录选择。workspace_choose 不接收 React 提供的绝对路径，只把系统对话框的选择转发给现有 RuntimeClient。取消保留原目录，同一时刻只允许一个选择窗口。使用 tauri-plugin-dialog 2.8.4；没有为 React 开放 filesystem 插件权限。
- Node 新增 workspace.state / open / close / list / read，复用原 Handler Registry 和 JSONL。实际文件读取、类型 / 大小 / 编码校验均由 Node 完成；不经 SQLite，也不调用模型。
- 目录授权使用随机 ID，切换或关闭后旧 ID 失效，读取完成前再次检查。取消的打开请求不会在后台建立授权。重启不恢复路径，须再次主动选择。
- 路径只接受受限相对形式，拒绝目录穿越、绝对路径、反斜线、流名称和 .git；逐段检查链接、核对 canonical 路径和根目录身份。打开文件后比对文件身份，并在读完后检查身份、大小和修改时间变化。
- 仅预览常见 UTF-8 文本 / 代码，拒绝二进制控制内容；单文件最多 64 KiB，实际有界读取，JSONL 响应留在现有预算内。目录只枚举最多 200 项并受响应字节预算限制，超限明确提示；符号链接等条目不可进入。
- 这是应用级读取范围，不是抵御恶意本机进程持续替换文件的操作系统沙盒；不据此授予未来 Shell / 写入工具权限。

## 页面

新增“工作区”导航页，提供选择 / 切换 / 关闭、面包屑、当前目录筛选、文本预览与内容复制。复用主题变量与现有 CopyButton；HTML、Markdown、SVG 均按文本显示，不执行或自动加载媒体。

文件、目录及授权切换均有迟到结果保护。取消选择保留预览，结果未知时从 Node 状态恢复；已确认成功后清除过时错误。隐藏页面保留现有聊天草稿。文件内容与绝对路径不写入浏览器存储、事件、Transcript 或日志，不自动发送模型。
