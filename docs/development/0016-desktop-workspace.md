# V0.4.2：可日常使用的桌面工作台

日期：2026-11-26。基于已推送的 `bc59531 feat(chat): 切换会话保留草稿与发送重试状态`。

## 目标与授权

用户要求持续自动开发、稳定后直接提交推送，直到能看到实际可使用的页面。本轮将现有功能组织成完整高度工作台，不再继续堆叠长页面。修改前重新阅读 ADR-0001，保留原组件、请求与领域边界。未改动 Runtime / Storage、Provider Registry、Task、Scheduler 或 Agent Loop。

## 实现

- 窗口顶部采用紧凑品牌 / 连接状态 / 导航，默认进入会话。左侧固定宽度会话列表，右侧标题、消息、输入分区；列表与消息各自滚动，窗口本身不随长消息变成纵向长页。
- 消息区占用剩余空间，输入框、模型选择和发送操作位于固定下方。支持“回到最新”；历史分页、Markdown / 代码复制、分支、重置、停止 / 继续与草稿全部复用现有逻辑。
- 会话信息、分支来源与原生累计用量放在“详情与用量”面板。支持 Escape 关闭；原始模型内容仍可按条展开。
- 640 CSS 像素以下，在列表与对话之间切换，选择会话后自动返回对话；空工作台提供可实际使用的“新建会话 / 配置服务商”入口。
- 新增 workspace.css 组织工作台布局与主题，复用既有组件和样式。默认正式窗口为 1120 × 800，最小 720 × 560，标题为 Pi Studio；网页标题、语言及图标同步替换模板。
- 修复实际窗口检查暴露的恢复竞态：会话保存的 Provider 已删除时，不再用失效配置覆盖有效目录。目录先返回与状态先返回都校验 Provider 可用性。模型错误与 Provider 错误分开，换到成功目录后清除旧模型错误，同时保留草稿。
- README 改为实际启动、服务商配置、聊天操作、验证与当前能力说明，不再保留空白项目模板介绍。

- 独立命名空间真实 Tauri 桌面：创建 / 搜索会话、本地演示模型发送、Markdown 展示、停止 / 继续、累计用量面板均通过。停止后继续未增加用户消息。截图使用独立演示数据；演示凭据与自定义配置已清理，系统凭据数归零。
- 正式工作台沿用原有数据库与凭据；未在正式数据上自动发送模型请求。
