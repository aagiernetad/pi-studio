## 问题与实现

现有模型菜单能设置推理档位，但实时状态只提取文本，历史默认正文也忽略 thinking 内容。核对已安装的 pi-ai / pi-durable 1.5.0：LiveDoc.generation.message 和助手历史已经包含原生 thinking、redacted 与签名，直接读取即可，不增加模型请求、Agent Loop、数据库或调度器。

- conversation.chat.status 增加 phase、partialThinking、thinkingTruncated。按原生内容块区分等待、思考和回复；空闲时清除实时内容。思考预览只保留末尾 12000 字符，完整原生历史不截断；redacted 内容及签名不进入预览。
- React 新增共用 ThinkingBlock，实时与历史均默认折叠，纯文本展示，不解析 HTML、不加载远程媒体。轮询更新不强制展开或重置用户的折叠选择。
- 历史跳过错误回复及遮蔽块的思考，仅有思考的助手记录不显示占位 JSON 或空的正文复制按钮。原有模型原始内容详情保持手动查看方式。
- 新提交 / 继续的乐观状态清除旧预览，继续保留会话切换取消守卫、草稿、幂等重试、停止和分页机制。
- CSS 复用现有明暗变量，限制展开高度与长文本换行；无额外定时器或动画。
