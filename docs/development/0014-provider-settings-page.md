# V0.4.0-A3：服务商设置与失败恢复

日期：2026-11-26。基于已推送的 `c6a974a feat(ui): 完善正序消息阅读与快捷发送`。

## 核查与范围

实施前重新阅读 ADR-0001，核对 Git、ProviderSettings / CustomProviderSettings、现有模型目录 / 凭据 / 测试 IPC 与页面回归。此前设置仍套在旧折叠区中，模型目录与凭据状态用 Promise.all 一起读取，单项失败会丢弃另一项的成功结果；目录无内容与读取失败的反馈也不完整。

本轮只调整现有 React 组件与样式，服务商配置、独立系统凭据、共享 Models、Durable 与 Tauri / JSONL API 均不改变。没有新增 Store、凭据副本或 Provider Registry。

## 改动

- 移除独立设置页内部的旧折叠容器，保留“密钥与连接 / 自定义配置”切换入口。凭据与模型测试分为两个有标题的区域，明确“保存凭据”和“连接通过测试”的区别。
- 以 Promise.allSettled 分别处理模型目录及凭据状态结果：模型读取失败但凭据状态已确认时，可以继续保存 / 删除密钥；凭据状态不可确认时，写入和模型测试仍禁用。现有 active / mounted / running 与忙碌状态保护保留。
- 模型目录失败与空模型使用不同提示。凭据读取 / 保存错误位于凭据区域，连接测试错误位于模型区域；通用错误信息不回显底层异常。连接失败不清除已知凭据状态，可再次测试。
- 服务商列表失败提供明确重试入口，禁用失效列表及编辑器；空目录提供“添加自定义服务商”入口，沿用现有配置表单。
- 自定义配置使用响应式双列布局。首次读取显示加载状态，无配置显示填写指引，读取 / 未确认写入失败可重试读取，未知结果仍禁止继续写入直至刷新确认。
- 密钥仍仅从非受控密码框提交至现有安全保存命令，保存后清空；切换服务商、设置模式或离开页面均卸载 / 清空未保存输入。操作进行中仍禁止切换或重复执行。
- 原“折叠再展开清空密钥”的旧测试已改为新“设置模式切换清空密钥”的入口，保留同一安全行为验证；原有迟到模型结果保护继续测试。
