## 本轮实际功能

| 功能 | Pi Studio 行为 |
| --- | --- |
| 四套主题 | 深空黑曜、暖炭玄岩、白昼冷晶、暖白画册；可跟随系统或固定明暗，并分别记住深浅预设 |
| 外观设置 | 主题 / 钴蓝 / 鸢尾紫 / 琥珀金 / 纯银钛强调色、三档圆角、侧栏密度、阅读宽度、四组本地等宽字体、连字 |
| 场景与动效 | 光学效果 / 专注阅读 / 静默省电组合；环境光、过渡和回到最新滚动控制；遵循系统减少动态效果 |
| 备份与恢复 | 只导出受校验的外观字段与明暗模式；支持导入 JSON、恢复默认，拒绝额外字段、无效枚举和过大文件 |
| 模型弹层 | 当前模型胶囊、服务商切换、模型搜索、接口支持状态、真实目录能力与刷新；Escape 一次关闭并恢复焦点，生成时禁止更改 |
| 代码阅读 | 代码顶栏吸顶；48 行起可手动收起 / 展开，默认不截断；折叠后仍复制完整代码，保留滚动锚点 |
| 对话大纲 | 对已加载用户问题搜索、跳转，可沿原分页继续加载更早问题；Alt+上下键跳转，不抢占输入焦点 |
| 紧凑侧栏 | 新建、按需命名、图标搜索 / 清除；外观入口位于侧栏底部 |
| 起始布局 | 空会话问候与输入居中，有历史时恢复独立消息滚动和底部输入 |

所有模型名称、能力和目录从现有 IPC 获取；外观配置仅写入浏览器外观偏好，不写入密钥、Transcript 或数据库。代码字体缺失时使用系统等宽回退，不下载外部字体。

## 守住的边界

- 保留草稿 Map、未确认发送 UUID、旧页隔离、分页锚点、迟到请求保护、凭据清空和忙碌导航限制。
- 外观导入离开页面或发生新选择后，迟到结果不再写入。未知字段或敏感字段不进入外观存储，也不回显导入文件内容。
- 模型选择只影响后续发送，不自动请求模型；既有停止 / 继续 / 重置语义不变。
- 不将累计用量误当当前上下文，不固定显示 512K、5 小时配额或未经测量的 tok/s。
