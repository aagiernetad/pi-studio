# V0.4.0-A2：正序消息阅读与快捷发送

日期：2026-11-26。基于已推送的 `8e71837 feat(ui): 增加会话、服务商与诊断导航`。

## 核查与范围

实施前重新阅读 ADR-0001，核对真实 Git、ConversationPanel / Transcript / Chat 与既有回归。原生历史 IPC 始终倒序分页，前端此前也按倒序展示，输入框位于历史之前。本轮只调整 React 阅读与输入体验，复用全部现有请求、组件和分页保护。Rust / Node / Durable 数据、凭据和协议不变。

- 消息按 Entry ID 正序展示，最新消息位于底部；服务端仍按原不透明游标倒序取页。顶部提供“加载更早记录”，旧页补入消息前端后保留阅读锚点，重叠 ID 去重。
- 消息区限制高度并支持键盘焦点与滚动；首次加载 / 刷新定位最新消息。页面隐藏时延后计算，重新显示后通过 ResizeObserver 完成定位，避免高度为零时误算。卸载时断开观察。
- 保留异步取消、分页 generation 与分支 mounted 保护；加载途中切换会话或刷新仍淘汰迟到旧页。原始模型内容仍可展开，Markdown、代码复制、分支与上下文重置边界保留。
- 输入区移至消息区下方，模型选择使用响应式双列；会话列表独立滚动。用户 / 助手 / 上下文边界使用现有深色配色区分，原生控件跟随深色模式。会话编号和创建时间收进“会话信息”，日常消息头不再显示技术编号。
- Ctrl 或 Command + Enter 调用既有 send，沿用原业务 UUID 与 working 锁；Enter 换行，输入法组合确认及按键自动重复不发送，禁用输入时不可通过快捷键绕过。
- 分支、用量、搜索、重命名、停止 / 继续和目录同步复用原功能，没有新增 Agent Loop、Scheduler、Store 或 API。
